## Human-facing destination rule

This repository `notes.md` file is an immutable project/source log and may keep newest entries at the top. When an entry is promoted into the live `Ben` vault, the destination note must follow `OBSIDIAN-NOTE-UX-STANDARD.md` for its actual note type. Do not copy this source-log structure wholesale into a human-facing project note.
